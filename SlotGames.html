Project Overview

Slot Games is a browser-based slot machine platform built with PixiJS for smooth, GPU-accelerated 2D reel animations and game rendering. The backend is powered by NestJS with MongoDB for persistent player and game data, and Redis for fast in-memory session and state management delivering a scalable and real-time slot gaming experience.

Key Highlights

  • PixiJS Frontend: High-performance GPU-accelerated 2D reel animations and game rendering powered by PixiJS.
  • NestJS Backend: Scalable backend architecture handling game logic, win calculations, and API endpoints.
  • MongoDB: NoSQL database for storing player profiles, game history, and payout records.
  • Redis: Real-time session handling and in-memory state management for fast, responsive gameplay.
  • Win Detection Logic: Custom server-side logic to evaluate winning combinations and payout multipliers.
  • Responsive Layout: Fully playable on desktop and mobile browsers without any downloads.
