Project Overview

Original Games is a multiplayer browser-based gaming platform built with PixiJS for high-performance GPU-accelerated 2D rendering. The backend is powered by NestJS with MongoDB for persistent game data and Redis for real-time session and state management. The bet panel interface was built using HTML/CSS, TypeScript, and Tailwind CSS, delivering a polished and responsive user experience.

Key Highlights

  • PixiJS Frontend: GPU-accelerated 2D game rendering using PixiJS for smooth, high-performance visuals.
  • NestJS Backend: Scalable and modular backend architecture built with NestJS to handle game logic and APIs.
  • MongoDB: Flexible NoSQL database for storing player data, game sessions, and leaderboards.
  • Redis: In-memory caching and real-time pub/sub for fast session handling and live game state sync.
  • Bet Panel: Custom bet panel UI built with HTML/CSS, TypeScript, and Tailwind CSS for a clean, responsive experience.
  • Cross-Platform: Runs on all modern browsers across desktop and mobile devices.
